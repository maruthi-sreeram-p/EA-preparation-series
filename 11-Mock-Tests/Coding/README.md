# Coding Mocks

**Weeks 10–11 + the coding section of the Week 12 full-length mocks** · [← Mock Tests](../README.md)

## Format
2 problems in 60 minutes (one easy–medium, one medium), in Java, in a plain editor or the test platform's editor — no IDE autocomplete.

## 📅 Tasks
- [ ] Week 10 — Mock 1: topics from DSA weeks 1–9 → `mock-01/` (problem statements, your solutions, error review)
- [ ] Week 11 — Mock 2: topics from DSA weeks 1–10 → `mock-02/`
- [ ] Week 12 — the coding section of each full-length mock → `full-01/`, `full-02/`, `full-03/`

## 💡 Test Strategy
- Read the constraints first; they tell you what time complexity you need
- If time is short, submit a correct brute force — on most platforms, passing some test cases still earns partial marks
- Test edge cases yourself: empty input, one element, duplicates, negative numbers, very large values
- Know fast input with `BufferedReader` in case the platform reads from standard input
