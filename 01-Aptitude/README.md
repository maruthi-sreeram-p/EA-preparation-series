# 01 · Aptitude

**Weeks 1–9:** 30 min a day · **Weeks 10–12:** mixed practice + mock tests · [← Main README](../README.md) · [Roadmap](../ROADMAP.md)

## 🔁 Every Week
- [ ] Days 1–6: 15–20 questions a day on the week's topics
- [ ] Write a short formula-and-shortcut sheet for each topic (file names are listed in each folder's README)
- [ ] Log every wrong answer in `mistakes.md` (in this folder): the question, your mistake, the right method
- [ ] Day 7: timed test — 20 questions in 25 minutes on the week's topics; record the result below
