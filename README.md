A structured, week-by-week preparation plan for a **Java Full Stack Developer Intern** role: aptitude, Core Java, DSA in Java, SQL, Spring Boot, React, CS fundamentals, a capstone project, and interview practice.

📅 **Plan:** 12 weeks — see [ROADMAP.md](ROADMAP.md). Every topic folder has a `README.md` with its day-by-day weekly tasks.

## 🛠️ How This Repo Works

- **Weekly tasks** live in each topic folder's `README.md`. Tick them off by changing `- [ ]` to `- [x]`.
- **Notes** are Markdown files named `NN-topic-name.md` (for example, `04-percentages.md`).
- **Java programs** are standalone. Run any file with `java FileName.java` — any JDK 11+ can run a single source file directly.
- **DSA solutions** each include the problem, approach, time/space complexity and test cases in `main`.
- **Interview questions** go into each section's `interview-questions.md` as you learn.
