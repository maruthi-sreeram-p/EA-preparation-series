# React

**Week 9** · [← Frontend](../README.md)

This week you build `task-tracker-ui/`, the React frontend for the Task Tracker API from [05-Spring-Boot](../../05-Spring-Boot/).

## 📅 Week 9 Tasks
- [ ] Day 1 — Setup: install Node.js (LTS); create the app with `npm create vite@latest` (React template); JSX, components, props, folder structure → `01-react-basics.md`
- [ ] Day 2 — State: `useState`, handling events, conditional rendering, lists and keys → `02-state-lists.md`
- [ ] Day 3 — Effects & forms: `useEffect`, fetching data with loading and error states, controlled forms → `03-effects-forms.md`
- [ ] Day 4 — Routing: React Router routes, links, URL params, protected routes → `04-routing.md`
- [ ] Day 5 — Connect: enable CORS in Spring Boot, build the login form, store the JWT and send it in the `Authorization` header
- [ ] Day 6 — Finish: share the logged-in user with the Context API; list, add, complete and delete tasks; basic styling
