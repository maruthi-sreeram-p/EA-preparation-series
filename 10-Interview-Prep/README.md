# 10 · Interview Prep

**Weeks 1–11:** small ongoing tasks · **Week 12:** full focus · [← Main README](../README.md) · [Roadmap](../ROADMAP.md)

## 🔁 Ongoing (Weeks 1–11)
- [ ] Every day, in the revision block: answer 5 questions from any `interview-questions.md` out loud
- [ ] Week 3: first resume draft — skills, education, achievements → `resume-notes.md`
- [ ] Week 9: add the Task Tracker project to your resume
- [ ] Week 11: add the capstone project to your resume

## Week 12 — Interview Mode
- [ ] Day 1: "Tell me about yourself" — a 60–90 second answer, written down and practised aloud → `hr-questions.md`
- [ ] Day 2: Answers to 15 common HR questions (why this company, strengths and weaknesses, where you see yourself in 5 years, why we should hire you) → `hr-questions.md`
- [ ] Day 3: 5 STAR stories: teamwork, conflict, failure, learning something fast, taking the lead → `star-stories.md`
- [ ] Day 4: A 2-minute project walkthrough + answers to 10 likely project questions → `project-walkthrough.md`
- [ ] Day 5: Company research: products, tech stack, recent news; 3 questions to ask the interviewer → `company-research.md`
- [ ] Day 6: Final resume review against the checklist below
- [ ] Two mock interviews with a friend or senior (one technical, one HR); write down what went wrong

## 📄 Resume Checklist
- [ ] One page, PDF, simple layout
- [ ] Skills match the job description (Java, Spring Boot, React, MySQL, Git)
- [ ] Each project: what it does, the tech stack, and one concrete detail or number
- [ ] GitHub and LinkedIn links work
- [ ] No spelling mistakes — read it out loud once
